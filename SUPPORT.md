# Support

## Getting help

Search the [documentation](docs/) and existing
[issues](https://github.com/mirza-rizvi/shelf/issues) first. If the problem is not
already covered, open a bug report using the repository's issue form.

Include the Shelf version, Chrome or Chromium version, operating system,
reproduction steps, and expected behavior. Remove private tab URLs, titles,
screenshots, and exported backup data before posting.

Support is community-maintained and provided on a best-effort basis. There is no
guaranteed response time.

## Security reports

Do not disclose vulnerabilities in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).
